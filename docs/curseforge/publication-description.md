# Zian Manager

Configure mob templates, shared dungeon encounters, waves, personal loot chests and dialogue NPCs using native administrative menus.

Chest rewards are reserved before delivery and released after 30 server ticks (1.5 seconds at 20 TPS) so the opening animation can finish. Repeated clicks keep one reservation. Keyless chests retain their reuse time; keyed chests prevent rapid overlapping key use.

Create dungeon arrival groups and capture each point from your current position. Move or remove saved points, then link an NPC button to select a safe point at random. Multiple dungeons can share one world, and changing a visible name preserves the link. Entry respects existing daily world-time restrictions.

Daily-time profiles support ranks, reset schedules, notices and an administrator-configurable HUD. The equipment catalog includes themed tools with diamond-equivalent statistics and 1636 durability.

Install on client and server: Minecraft 1.21.1, Java 21 and NeoForge 21.1.252 or compatible newer 21.1.x. Lootr and LuckPerms are optional integrations. Youer/Bukkit permissions are supported when available; those plugins are not required for standalone NeoForge operation.

Durable receipts and recovery protect unfinished rewards. Optional SQLite migration and maintenance preserve pending operations. Back up the world before upgrades.
