# Zian Manager 0.1.1

Archivo del mod: `zianmanager-0.1.1.jar`. Tipo de publicación: Release. Minecraft 1.21.1; NeoForge; Java 21. Se instala en cliente y servidor. No subas el ZIP de documentación como archivo principal.

Sustituye el JAR anterior con Minecraft y el servidor cerrados. Conserva una copia del JAR y del mundo. Mantén un solo JAR de Zian Manager en cada carpeta mods. No borres el almacenamiento: las configuraciones, NPC y esperas se conservan.

Para las nuevas apariencias: `/zianmanager` → Personajes y diálogos → seleccionar o crear NPC → Apariencia → Skin. Instala el nuevo JAR en el cliente para disponer de los ocho PNG nuevos.

Los textos de cambios y descripción están en esta carpeta, en español e inglés. No se han publicado en CurseForge ni se ha reemplazado el JAR del servidor activo como parte de esta preparación.
