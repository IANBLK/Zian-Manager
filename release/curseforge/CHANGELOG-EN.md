# Zian Manager 0.1.0-beta.1

First public beta for Minecraft 1.21.1 / NeoForge. Based on alpha.22, retaining existing item IDs, configurations and network protocol.

Includes configurable mob/boss templates, shared dungeon zones and waves, personal/keyed loot chests, independent regular-mob drop chances, multi-button dialogue NPCs, fantasy equipment and configurable daily time budgets by world.

Publication metadata, installation instructions, artwork notices and compatibility documentation have been prepared for the beta release. No new gameplay system is introduced by the version promotion.

Install the same beta.1 JAR on client and server, replacing earlier Zian Manager files. Back up your world and settings first. Lootr and LuckPerms are optional; Cobblemon and RCT are not required.

Rassvet-specific server companions, Casas generation, rank settings and plugin configurations are separate from this JAR.
