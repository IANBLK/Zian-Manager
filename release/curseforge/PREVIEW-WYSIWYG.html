🏰 ZIAN MANAGER — SHAPE YOUR ADVENTURE

Turn the places you build into adventures worth exploring. Zian Manager gives administrators an in-game editor for dungeon encounters, personal rewards and dialogue NPCs, together with fantasy equipment and optional daily time limits for selected worlds.

Minecraft 1.21.1 • NeoForge • Java 21 • Client and Server

🛠️ BUILD AND CONFIGURE INSIDE THE GAME

Open /zianmanager as an administrator to manage mobs and bosses, reward tables, dungeon zones, personal loot chests, dialogue characters and world time limits.

Create a mob template, choose its rewards, define an encounter area and place your chests or NPCs. The editor keeps configuration close to the world you are building, with selectors, item icons and zone previews.

Administrators build and configure their own encounters. Zian Manager does not automatically generate dungeon structures or populate every world.

⚔️ MOBS, BOSSES AND SHARED ENCOUNTERS

Use existing entity types as encounter templates and customize their name, health, attack damage, armor, toughness, knockback resistance, potion effects and equipment. Their original entity AI is retained; bosses can display a boss bar.

Configure shared waves with one or several selected templates. Automatic zone appearances can start with 1–3 mobs, add 2 per additional player and cap the wave at 8 mobs, according to the zone settings.

Choose wave count, pauses, encounter regeneration and completion rewards. Several players can take part in the same encounter without creating a duplicate wave for each participant.

📐 DUNGEON ZONES WITH A FIXED CENTER

Create a zone from the block beneath you, then expand its width, length, height and depth around a fixed center. A visual preview helps you see the bounds and appearance area while configuring it.

Mobs can appear automatically on suitable free ground inside the zone, so each mob does not require a separate hand-placed point. Configurable floating text shows the zone name and its regeneration or next-wave countdown.

🗝️ PERSONAL LOOT CHESTS

Give every player their own reward roll. Configure a chest’s reward table and per-player refill timer, or use a sealed chest that consumes its matching key.

Keyed variants can operate without a refill cooldown because every opening spends a key. A two-second key-use delay helps control repeated requests. Ordinary refillable chests keep their configured renewal.

Opening a chest delivers its loot and reports the reward in chat. Items go to the player’s inventory; overflow is placed beside the player. Custom chests are protected against survival breaking, explosions and piston movement, with administrative removal available.

🎲 REWARD TABLES AND DROP CHANCES

Edit rewards through item rows with icons, quantities and weights. Copy an item from your hand, including its supported components, without consuming that item.

Weighted selection is available for mobs, bosses and chests. For ordinary mobs, independent percentage drops can be used instead: a mob may drop one reward, several rewards or nothing.

Bosses and chests retain weighted reward selection. Rewards and delivery receipts persist; ambiguous deliveries remain available for administrative review instead of being automatically paid twice.

💬 DIALOGUE NPCS AND COMMAND BUTTONS

Place a human-style character, select a supplied skin, write multiline dialogue and add a main action with additional command buttons. Buttons can have their own labels and cooldowns.

Guide players toward an arena, present server destinations or connect a character to commands supplied by your own setup. NPC editing and command configuration remain administrative features; players interact with the actions you configure.

✨ FANTASY EQUIPMENT

Discover themed weapons, mining hammers, keys, chest models, enchantable hats and reimagined tools with imported geometry and textures.

Weapons include configured abilities and cooldowns. Hats behave as enchantable helmets, while reimagined tools retain their vanilla material behavior with their configured improvements.

Equipment is available through the mod’s creative and administrative tools and can be assigned to encounter rewards. This beta does not provide a complete survival crafting progression.

⏳ OPTIONAL DAILY WORLD TIME LIMITS

Set daily playtime budgets for selected dungeon or farming worlds. Separate profiles can keep Dungeon, Nether, End and Farmeo consumption independent.

Configure rank permissions, weekday/weekend allowances, unlimited-time bypasses, temporary bonus minutes, administrative time removal and reset or exhaustion messages.

A compact, movable timer displays the active profile. Exit destinations can use the supported native bed/spawn behavior or a command configured for your server. Travel checks help enforce exhausted balances; unusual hybrid teleport routes need their own compatibility testing.

Time limits are optional. Only the worlds assigned to an enabled profile are limited.

📦 INSTALLATION AND REQUIREMENTS

  • Minecraft: 1.21.1.
  • Mod loader: NeoForge 21.1.252+ for Minecraft 1.21.1.
  • Java: 21.
  • Installation: the same Zian Manager version on client and server.

Put the JAR in the mods folder on both sides. Replace the previous Zian Manager file instead of keeping duplicate versions. Back up your world and settings before updating.

🔗 OPTIONAL INTEGRATIONS

Lootr is optional. Zian Manager’s personal chests use their own reward journal and are excluded from Lootr conversion. Ordinary Lootr chests retain their own behavior.

LuckPerms is optional for permission and rank setups. Cobblemon, RCT API, Zian RCT and Zian Utilities are not required for Zian Manager to load.

NPC commands and configured teleport commands can use external mods or plugins, but those commands must exist and be permitted on your server. The separate Rassvet server companion and Casas world generator are not included in this mod JAR.

⌨️ USEFUL COMMANDS

/zianmanager — Open administration.
/zianmanager time — View configured world time balances, where permitted.
/zianmanager pending — List your pending rewards.
/zianmanager claim <ID> — Claim an available pending reward.

Administrative time management includes removetime, bonustime and profile-specific worldtime actions. Grant editing permissions only to trusted administrators.

🚧 BETA — ACTIVE DEVELOPMENT

First public beta • Minecraft 1.21.1 • NeoForge • Java 21

🏰 FIRST PUBLIC BETA

Promotes alpha.22 to 0.1.0-beta.1, retaining item IDs, configuration formats and the network protocol. This promotion prepares the existing gameplay systems for public testing.

⚔️ FEATURES INCLUDED

  • Configurable mob and boss templates with equipment and effects.
  • Shared dungeon zones, scalable automatic appearances, waves and regeneration countdowns.
  • Personal loot chests, matching keys and configurable refill behavior.
  • Weighted reward tables and independent regular-mob drop chances.
  • Dialogue NPCs with multiple command buttons.
  • Fantasy weapons, mining hammers, enchantable hats and tools.
  • Independent daily time profiles, permission tiers, bonuses and administrative removal.

📦 PUBLICATION AND COMPATIBILITY

Added beta publication metadata, a project icon, installation instructions, artwork notices and CurseForge materials. The NeoForge minimum is declared as 21.1.252 for Minecraft 1.21.1.

The original code remains MIT licensed; imported artwork retains its separate permissions. Rassvet-specific companions, rank settings and Casas generation remain separate from the JAR.

🧪 VALIDATION

78 unit tests • 81 verified models • 4 native server/restart passes, including scenarios with and without Lootr.

The smoke runner now creates a fresh fixture world for each invocation and shares it only between its two passes, preventing expired markers from previous test runs from causing false cooldown failures.

🔄 UPDATE NOTES

Lootr and LuckPerms remain optional. Cobblemon and RCT are not required. Test your particular hybrid plugin and rendering setup before a wider rollout.
