# Publicar Zian Manager beta.1

## Archivo principal

Subir únicamente `zianmanager-0.1.0-beta.1.jar` como archivo del mod. El ZIP de preparación reúne documentación e imágenes; no debe subirse como sustituto del JAR.

## Campos del proyecto

- Nombre: **Zian Manager**.
- Resumen: **Create configurable dungeon encounters, personal loot chests and command-driven dialogue NPCs with an in-game editor.**
- Juego: **Minecraft**; tipo de proyecto: **Mods**.
- Categoría principal: **Adventure and RPG**. Adicionales: **Server Utility** y **Armor, Tools, and Weapons** (seleccionar las equivalentes disponibles en el formulario).
- Autor visible: **IANBLK**.
- Descripción principal: copiar `DESCRIPTION-EN.md`. `DESCRIPTION-ES.md` queda como traducción complementaria.
- Licencia de proyecto: **Custom**, con `PROJECT-LICENSE.txt` y el texto de `LICENSE.txt`, porque MIT cubre el código y el arte conserva permisos separados.
- Icono: `images/icon.png`; banner y galería son opcionales. Las imágenes de galería son capturas reales y el icono es ilustración del proyecto.
- Fuente: https://github.com/IANBLK/Zian-Manager/tree/feature/dungeon-core
- Incidencias: https://github.com/IANBLK/Zian-Manager/issues

## Campos del archivo

- Nombre visible: **Zian Manager 0.1.0-beta.1 — NeoForge 1.21.1**.
- Tipo: **Beta**.
- Versión de Minecraft: **1.21.1**, únicamente.
- Cargador: **NeoForge**, no Forge ni Fabric.
- Changelog: copiar `CHANGELOG-EN.md`.
- Relación opcional: **Lootr**. No marcar Cobblemon, RCT, Zian Utilities ni plugins Bukkit como dependencias obligatorias.
- Debe instalarse en cliente y servidor; Java 21 y NeoForge 21.1.252+.

## Revisión final

Comparar el SHA-256 del JAR con `SHA256SUMS.txt`. No subir mundos, configuraciones de Rassvet, credenciales, JAR de otros mods ni complementos de servidor. La autorización para distribuir los recursos quedó confirmada por el propietario; conservar sus documentos fuera del paquete público. Las condiciones específicas de los paquetes siguen vigentes.

El paquete está preparado para una carga manual. No se ha creado ni enviado un proyecto de CurseForge, ni se garantiza la aprobación de moderación.

Referencias oficiales: https://support.curseforge.com/support/solutions/articles/9000197241-creating-and-submitting-a-project y https://support.curseforge.com/support/solutions/articles/9000197242 (la guía actualizada en 2026 permite que una Beta aprobada sincronice el proyecto con la aplicación cuando el usuario selecciona betas).
